# 文章阅读与总结

**场景**：让模型阅读一篇文章，输出摘要、结构化总结或学习材料；遇到不懂的概念时，让模型系统性地解释。

## 1. Gemini：摘要与选题

**摘要**

```
Summarize the article (link below) for me, include bullet points of the main points.
```

**选题头脑风暴**

```
Brainstorm 5 blog ideas about Gemini for the Zapier blog.
```

## 2. NotebookLM：阅读文章

**核心主题、观点与结论**

```
请阅读文章，输出文章的核心主题，主要观点和事实，以及结论
```

**简报文档**

```
请阅读文章，输出简报文档
```

**目录**

```
请阅读文章，输出目录
```

**学习指南**

```
请阅读文章，输出学习指南
```

**观点与收获**

```
请仔细阅读文章，罗列出来文章的主要观点和事实，以及学到了什么？
```

## 3. 深度总结（输入法自定义短语）

**`zjqw`：详细的结构化总结**

```
请你先阅读全文，然后认真思考文章内容，再对内容做反思，最终总结全文，越详细越好，麦肯锡地结构化表达出来，以及注意尽量有数据支撑和洞察。
```

**`xpl`：观点、反思与评论**

```
请你仔细阅读全文，提取文章核心要点，要包含来自数据方面的洞察，在对其进行反思和评论，最终将｛核心观点｝，｛内容的反思｝，｛客观评论｝分段落撰写出来，撰写风格要去 AI 化，符合人类习惯。
```

## 4. 解释不懂的内容

```
请你全面和系统性的解释下

"""
{关键词 | 专业术语 | 专有名词}
"""

要求：越详细越嗨，以及注意专业性和清晰的表达。
```

## 补充：CLEAR 模型

写 prompt 时的检查清单：

1. Clarity
2. Structure
3. Contextualization
4. Iterative Feedback
5. Role Assignment
