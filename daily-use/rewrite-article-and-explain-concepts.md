
# 文章转写与概念补充

**工具**：Cline + MCP（Tavily 搜索）

## 1. 转写文章

**场景**：搜索到一篇英文技术文章后，让模型以编辑身份转写为通顺的中文。

```
你是一名资深{领域}编辑，同时具备优秀的文笔。请将文章转写为中文，确保段落清晰，文字连贯，可读性强。必要时调整段落结构，确保内容具备良好的逻辑性。
```

## 2. 搜索并补充概念

**场景**：文章中出现不熟悉的概念，让模型搜索、解释，并整理进已有文档的合适位置。

```
使用 tavily 搜索，并解释什么是 {概念}。将文字整理为合适的段落，放入 {文档路径} 中合适的位置。帮助读者更全面地学习。
```

示例：`{概念}` = LiveCodeBench，`{文档路径}` = `@/docs/grok-3.md`。
