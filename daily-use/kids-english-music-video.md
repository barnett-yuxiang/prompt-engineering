# 儿童英语音乐启蒙视频制作

**场景**：从零制作一个儿童英语启蒙音乐视频（以 26 个英文字母为主题）。流程依次用到 ChatGPT（歌词与绘图 prompt）、Midjourney、Suno、tensor.art、CapCut。

## 1. 生成歌词和绘图 prompt

**1.1 分析爆款视频**

```
你是一名非常专业的内容创作者，这是一个爆款英语启蒙类的音乐视频，分析这个视频能爆火的原因，总结这个视频的文案特点，以及视频中音乐的风格
```

**1.2 写歌词**

```
根据刚刚总结的文案特点以及爆火原因，写一篇类似的歌曲歌词，这首歌的主题是给儿童介绍 26 个英文字母，要求歌词生动有趣，能够吸引小孩的注意
```

**1.3 生成场景系列**

```
现在给这首歌生成一个非常详细的场景系列（至少 26 个场景），要求每个场景都符合当前这首歌正在介绍的动物或者物品
```

**1.4 生成绘图 prompt**

```
创建非常详细的绘图 prompt，用于为每个场景生成图片，图片要采用适合小孩观看的风格，这些 prompt 我将用于在 Midjourney 中生成图片
```

## 2. 生成创作歌曲的 prompt

1. 在 YouTube 上找童谣歌曲频道，挑选合适的视频链接。
2. 在 SONOTELLER 粘贴链接，稍等会出现对该视频的分析；也可以用 Suno Prompt。

## 3. 生成歌曲

在 Suno 中，歌词用第 1 步的结果，Style of Music 用第 2 步的结果。

## 4. 生成歌曲配图

用 tensor.art，推荐 Disney 模型，NUKE 子类。

## 5. 视频剪辑

用 CapCut，比较费时间，需要调整视频、加字幕。
