# Skills Overview

我在用的 agent skill（技能）。

## 全局

- [humanizer](https://github.com/blader/humanizer) — 去除 AI 腔
- find-skills — 发现和安装 skill

安装：`npx --prefer-online skills@latest add blader/humanizer --global --agent codex claude-code`

## talk-with-ai 项目

- ask-matt — skill 路由器，不知用哪个时先问它
- grilling / grill-me / grill-with-docs — 对方案/设计高压追问
- diagnosing-bugs — 硬 bug / 性能回归诊断
- tdd — 测试驱动开发
- code-review — 对照 spec 和 coding standards review
- implement — 按 spec 或 ticket 实现功能
- to-spec / to-tickets — 对话转 spec / 拆 ticket
- domain-modeling — 建领域模型 / 维护 GLOSSARY
- research — 调研问题，输出报告
- prototype — 一次性原型，快速验证思路
- wayfinder — 大块工作拆成 decision ticket
- handoff — 会话压缩成交接文档
- teach — 教学某个技能或概念
- triage — issue / PR 分类
- codebase-design / improve-codebase-architecture — 模块设计与架构优化
